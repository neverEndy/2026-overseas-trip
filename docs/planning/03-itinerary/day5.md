# Day 5｜09/06（日）：南浦最後採買・賦歸

← [返回每日行程總覽](./index.md)

> **服裝建議：** 輕便舒服為主，方便通關與久坐飛機

今天沒有排定行程，退房後自由活動（睡到飽、採買、找地方吃飯都行），**16:00 準時回飯店集合前往機場**即可。

## 行程總覽

| 時間 | 行程 | 地點 | 備註 |
|------|------|------|------|
| 09:00 | 飯店退房、行李寄放櫃檯 | 阿爾班酒店 | 先辦退房，行李寄放後輕裝出門 |
| 09:00-16:00 | 自由活動：最後採買、午餐 | 南浦洞／西面自選 | 自由分流，見下方「自由活動參考」 |
| 16:00 | 集合、領回行李、整理托運 | 阿爾班酒店 | **準時集合**；確認退稅單據、伴手禮是否需要托運 |
| 16:30 | 出發前往金海機場 | 西面 → 金海機場 | 輕軌＋地鐵約 50 分鐘；或計程車約 35 分鐘（約 ₩17,000-20,000） |
| 17:30 | 抵達機場、辦理退稅、報到、託運行李 | 金海機場 第一航廈 | 國際線建議提前 2-3 小時抵達 |
| 19:20 | **登機時間** | 金海機場 CI187 登機門 | 通常起飛前 40 分鐘開始登機，登機門於起飛前 20 分鐘關閉，請提前在登機門候機 |
| 20:00 | 飛機起飛 PUS→TPE | CI187 中華航空 | 飛行約 2.5 小時 |
| 21:35 左右 | **抵達時間**：抵達桃園機場 | 桃園機場 第二航廈 | 台灣比韓國慢 1 小時，實際落地時間以航班動態為準，記得安排接駁回家交通 |

## 注意事項

- 若有退稅商品，記得在機場先辦理退稅（Tax Refund）再去報到櫃檯託運行李，部分商品需海關查驗。
- 出發前務必再次確認護照、機票、退稅單據都在隨身行李中。
- 16:00 是硬性集合時間，自由活動不要壓縮到回飯店整理行李的時間。
